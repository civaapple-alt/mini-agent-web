# 侧栏计划、目标与工作区信息架构

## 决策

运行详情抽屉按对象归属拆分顶层入口：

- `工作区` 管理环境、MCP、文件/Git、技能和内置工具权限；
- `计划` 展示 Plan Mode 状态和当前会话计划文件；
- `目标` 管理 Thread Goal；
- `README.md` 是工作区说明，不作为计划阅读器内容。

## 原因

Builtin Tools 的权限作用域是当前 Thread 的运行工作区，不是计划内容。Thread Goal
也有独立的运行生命周期和操作集合，继续与计划控制混排会让侧栏同时承担阅读、工具
授权和目标管理三种任务。拆分后，状态栏的计划详情仍能直接进入计划阅读器，历史
`plan_goal` Tab 标识则映射到目标 Tab 以保持兼容。

## 边界

计划文件仍通过 Gateway 的受控 Session 文件接口读取；前端只过滤计划路径，不扫描
工作区。计划阅读器保留 Markdown 阅读态和文件切换，Workspace 工具权限继续复用
原有 workflow settings API。
