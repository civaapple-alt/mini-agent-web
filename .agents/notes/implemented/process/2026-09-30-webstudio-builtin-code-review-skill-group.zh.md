# Web Studio 内置 code-review 技能组

## 决策

Web Studio 将本地仓库评审能力作为可选的内置技能组提供。资源包包含一个协调技能和四个专项技能。项目默认不启用该组，用户可在技能面板打开。

协调技能支持当前工作区、指定基线和整仓三种范围。未指定范围时先检查暂存、未暂存和未跟踪文件。工作区干净时询问用户，不把整仓评审当作默认范围。

评审只读取本地文件并返回报告，不访问或修改 GitHub。协调技能按兼容性、变更规模、模型上下文和测试覆盖四个方向委派独立子任务。主会话读取每个子任务的结果；无法委派时顺序执行并说明限制，子任务失败时列出未完成的专项。

## 实施

- 在 resources/builtin-skills/code-review 固化五个 SKILL.md，版本为 0.1.0。
- 修正 breaking-changes 副本的 frontmatter 名称，使其匹配目录名。
- 调整四个专项文档，遵循目标仓库的 AGENTS.md、文档和测试约定，不依赖 Codex 专属路径。
- 复用现有同步器、项目设置、App Server 技能发现和面板。组状态由运行时清单投影；未启用时 API 仍返回 disabled 组元数据。
- 主技能规范名称为 code-review:code-review，专项使用 code-review: 前缀。用户可使用 + code-review 启动组工作流。

## 验证证据

资源测试检查组版本、五个目录、frontmatter 名称、协调流程关键分支和总字节上限。同步测试覆盖幂等和组间独立替换。Gateway 测试覆盖未启用组和五项启用目录投影。前端 token 测试覆盖专项直接激活、组工作流和禁用组拒绝。

这些离线测试不调用模型 Provider 或 GitHub。子任务编排的运行行为由技能指令规定；本次验证不声称执行过真实模型评审。
