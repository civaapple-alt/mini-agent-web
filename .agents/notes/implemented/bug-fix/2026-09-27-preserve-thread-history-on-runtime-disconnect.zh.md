# 运行时恢复失败时保留已显示会话流

## 问题

App Server 断开后，Gateway 的恢复流程会重新读取 canonical Session 历史。读取失败时，`loadThreadHistory` 异常分支清空消息；恢复读取还会将聊天区域切换到整页加载态，导致已打开的会话流消失。

## 决策

- 恢复和事件缺口对账属于当前会话的后台刷新，不隐藏已有消息。
- 历史读取失败时保留页面已有投影并显示错误提示。
- 切换 Thread 时仍由会话切换流程先清除旧 Thread 投影，避免旧消息显示在新会话中。
- Gateway 离线时消息可以继续阅读；子任务列表和控制等在线操作仍需后端恢复。

## 验证

执行前端 lint 和 production build；未调用付费模型。
