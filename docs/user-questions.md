# Agent 问答

Web Studio 通过 App Server 内置 `ask_user` 工具接收 Agent 的澄清问题。
App Server 持有交互状态并运行等待中的 Turn；Gateway 只把按 Thread 路由的
回答提交给对应 App Server，不建立并行状态源。

## 会话流

每次最多显示一个问题，一个工具调用最多包含三个问题。问题可以提供单选项、
文字回答或跳过。最多一个选项显示“推荐”标签和推荐理由；推荐项不会预选或
自动提交。用户点选选项即提交并进入下一题，文字回答可以按 Enter 发送。

等待回答时，会话状态显示“等待用户回答”，工具卡展示当前问题。完成后，
`ask_user` 工具卡默认折叠为问题数量摘要；展开可查看每题的文字答案、选项标签
或跳过状态。普通工具结果继续使用既有工具卡。

## 能力与恢复

只有在 App Server `initialize` 中声明 `userQuestions` 的客户端才会获得
`ask_user`。答案通过 Gateway 的 Thread 路由端点提交，App Server 校验
Thread、Turn、工具调用和当前问题的身份，并在确认响应前持久化答案。相同答案
可以安全重试；冲突答案、过期交互和非当前问题会被拒绝。

刷新或重连后，Studio 从 `thread/read` 恢复当前交互。执行恢复时，App Server
沿用已持久化的答案，并重新显示尚未回答的问题。答案作为普通工具结果进入后续
模型请求；麦克风和语音输入不属于该交互。
