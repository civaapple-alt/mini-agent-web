# Web Studio 偏好设置

Web Studio 的设置窗口使用左侧分类菜单和右侧详情区。菜单按“偏好设置”和
“Agent 能力”分组；选择分类后，右侧显示该分类的内容。窄屏下菜单改为横向滚动，
详情区保持独立滚动。

## 分类

| 分组 | 分类 | 内容 |
| --- | --- | --- |
| 偏好设置 | 安全与运行 | 查看当前项目的待处理批准和授权存储；撤销已缓存的批准会重启当前 App Server。访问范围、审批策略和连续执行方式仍在顶部运行状态栏的“运行设置”中调整。 |
| 偏好设置 | 界面与外观 | 选择浅色或深色主题，设置流式输出自动跟随和代码、长文本自动换行。 |
| Agent 能力 | 模型设置 | 管理 Responses 供应商、模型、全局默认值、Goal Verifier 默认值和当前项目默认值。详情见[模型供应商与模型设置](models.md)。 |

## 保存

偏好设置分类共享同一个草稿；切换分类不会丢弃尚未保存的修改。使用详情区底部的
“保存配置”应用偏好，或使用“恢复默认”还原偏好默认值。关闭窗口会放弃未保存的
偏好修改。

模型设置独立保存。供应商、模型和默认值通过本地模型目录接口更新，不受偏好设置
页底部的保存按钮影响。API Key 由 Host 明文保存在用户配置目录的独立文件中；查询界面只显示是否已配置。文件不加密，Unix 上仅当前用户可读写。

## 安全与运行设置的边界

设置页中的批准信息是当前项目状态的只读投影，撤销操作由 Host/App Server 执行。
Web Studio 不缓存授权状态，也不以页面设置替代运行状态栏中的访问范围和批准策略。
