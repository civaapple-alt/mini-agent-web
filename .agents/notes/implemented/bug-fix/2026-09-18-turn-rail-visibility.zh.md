# Session Turn 轨道可见性修复

状态：Implemented

## 问题

初版把 `SessionTurnRail` 挂在每个用户消息行内部。用户滚动到助手内容时，消息行中的节点可能离开可视区域，
信息流只剩下背景竖线，无法提供 Session 导航。

## 修复

- 将轨道提升为 `ChatArea` 消息列表的独立导航列；
- 使用粘性定位保持轨道在回看长回答时可见；
- 节点仍通过已有消息锚点定位到对应用户输入，不改变 Turn 数据来源和状态判断；
- 轨道自身有界滚动，多轮 Session 不会无限扩展正文布局；
- 移动端继续隐藏轨道，正文恢复完整宽度。

## 验证

- `npm run lint`
- `npm test`
- `npm run build`
