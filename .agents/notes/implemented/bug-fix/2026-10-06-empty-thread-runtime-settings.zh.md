# 空 Thread 的运行设置读取

状态：implemented；日期：2026-10-06；范围：Web Studio Project 与 Session 设置

## 问题

在尚未发送第一条消息的空 Thread 中修改项目执行范围或审批策略后，刷新页面可能让界面回退到默认值。此前 UI 同时把这些字段保存在通用用户偏好和运行状态中，页面初始化读取了错误的数据来源。

## 决策

访问范围和审批策略属于 Project，打开 Thread 时从运行时快照读取，包括新建的空 Thread。连续执行方式属于当前 Thread，并保存在 Session 设置中。通用用户偏好只保留主题和界面偏好。创建或派生 Thread 后，Studio 显式读取待处理批准与运行快照，以显示服务端的当前值。
