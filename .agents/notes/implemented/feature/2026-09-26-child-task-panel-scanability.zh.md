# 子任务面板状态速览与渐进控制

状态：Implemented

## 决策

- 子任务列表首先回答“有多少、哪些在运行、哪些在排队、哪里需要处理”。数量按运行、排队、待处理、已结束区分，并用状态色辅助扫描。
- 默认行只显示标题、权威状态、耗时和当前可用的阶段/进展摘要。等待原因、恢复诊断、完整报告和尝试历史在展开后展示。
- 停止作为唯一快捷控制，并在提交前确认。暂停、steer、排队后续、修改提示词、继续和重试收在展开行的“更多操作”中；状态来源与控制请求仍由 Gateway/App Server 提供。
- 不伪造更细粒度的实时活动：没有阶段或报告时，摘要只显示“正在执行”。
