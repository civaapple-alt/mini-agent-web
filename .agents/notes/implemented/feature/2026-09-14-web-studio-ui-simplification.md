# Web Studio UI 交互、布局与主题升级

状态：Implemented

## 背景

原页面同时展示 Plan、Goal、Runtime 多条顶部状态栏，访问范围、审批策略和推进方式
又分散在输入栏底部；状态入口重复，运行中的 Project/Session/Turn 作用域不够集中。
主题还包含 Midnight 与 Cyberpunk，组件中存在较多直接颜色值，导致不同主题行为和对比度
不一致。

## 实现

- 新增纯展示状态选择器和 `StatusRail`，统一连接、运行、审批、停止、Plan/Goal 和最近结果；
- 详情抽屉增加“运行状态”，并将抽屉组织为“运行状态 / 计划与目标 / 工作区”，工作区内切换环境、MCP、文件与 Git；
- 访问范围、审批策略和推进方式迁移到状态栏运行设置弹层，保留完全访问二次确认和 Goal 接管提示；
- 输入栏保留任务输入、Slash、Mention、附件、排队、发送和停止，删除重复策略菜单；
- 停止审批中的 Turn 时保留审批卡但禁用操作，避免用户误以为审批已经消失或仍可执行；
- 增加移动端导航抽屉、详情抽屉 Escape 关闭、统一焦点环和减少动效支持；
- 主题收敛为 Light/Dark，旧主题值读取时迁移到 Dark，并将主要聊天、工具、审批、设置和错误样式改为语义 Token。

## 边界与验证

App 仍然持有运行、审批、Plan、Goal 和连接状态权威；本次没有新增 REST/WebSocket 接口。
状态栏和详情抽屉只消费现有状态与事件，不根据 UI 乐观推断终态。

验证结果：

- `npm run lint` 通过；
- `npm test` 通过，Node 测试 42 个，Vitest 测试 17 个；
- `npm run build` 通过；
- 保留了现有 Session/Turn 隔离、审批冲突、停止和 `/plan <任务>` 回归测试，并新增状态模型和状态栏组件测试。
